# Replication Journal Federation
Contains the website for the RJF, published at https://forrt.org/rjf/

## Publications and RSS feed

The website lists all articles published in the RJF member journals (for JOPD, only Verification Reports).

- **RSS feed:** https://forrt.org/rjf/feed.xml (the 50 most recent publications)
- **Full list as JSON:** https://forrt.org/rjf/publications.json

Both files are generated by `scripts/build_publications.py` and refreshed daily by the GitHub Action in `.github/workflows/update-publications.yml` (it can also be run manually from the Actions tab). Sources per journal:

| Journal | Source |
|---|---|
| Journal of Comments and Replications in Economics | DataCite (DOIs `10.18718/81781.*`) |
| Journal of Open Psychology Data | Crossref (ISSN 2050-9863), filtered to the Verification Reports section |
| Journal of Robustness Reports | Crossref (ISSN 3051-3200) |
| Replication Research | OAI-PMH of the journal's OJS site |
| ReScience C | `_bibliography/published.bib` in [rescience/rescience.github.io](https://github.com/rescience/rescience.github.io/tree/sources) |
| ReScience X | OAI-PMH of the journal's OJS site |

To add a journal, write a fetcher in the script, add it to `JOURNALS` and `fetchers`, and run `python scripts/build_publications.py` locally. If a source fails, the previous entries for that journal are kept and the workflow logs a warning.
